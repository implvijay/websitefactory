## 🎯 Getting Started

### Step 1: Start the Development Server

```bash
npm run dev
```

The application will start at: **http://localhost:5173**

### Step 2: Login

1. Open your browser to `http://localhost:5173`
2. Enter credentials:
   - Email: `admin@websitefactory.com`
   - Password: `password`
3. Click "Sign In"
4. You'll be redirected to the Dashboard

### Step 3: Create Your First Project

1. Click the **"+ New Project"** button
2. Fill in the form:
   - **Project Name**: Enter a name (e.g., "My Business Website")
   - **Industry**: Select from dropdown (e.g., "Technology")
   - **Theme**: Choose from 48 themes (12 base × 4 variants)
3. Click **"Create Project"**
4. You'll be redirected to the Project Editor

**What Happens Automatically:**
- ✅ 3 pages created (Home, About, Contact)
- ✅ Rich content generated for each page
- ✅ Menus created with navigation
- ✅ Theme applied to all pages

### Step 4: Edit Pages

1. In the left sidebar, click on a page (e.g., "Home")
2. You'll see the **Page Canvas** with sections
3. **Add Sections**:
   - Drag components from the left panel
   - Or click the "+" button
4. **Edit Sections**:
   - Click on any section to select it
   - Edit content in the right panel
   - Change colors, fonts, spacing
5. **Reorder Sections**:
   - Drag sections up/down
   - Or use the arrow buttons
6. **Delete Sections**:
   - Click the trash icon on a section

### Step 5: Build Menus

1. Click the **"Menus"** tab in the left sidebar
2. Select a menu or create a new one
3. **Add Menu Items**:
   - Click "+ Add Item"
   - Select page from dropdown (no typing needed!)
   - Or enter external URL
4. **Reorder Items**:
   - Drag items up/down
5. **Clone Menu**:
   - Click the "📋" icon to duplicate a menu
   - Modify the clone independently

### Step 6: Customize Theme

1. Click the **"Theme"** tab
2. **Browse Themes**:
   - See all 12 base themes
   - Each has 3 variants (Dark, Vibrant, Soft)
   - Total: 48 themes
3. **Preview Theme**:
   - Hover over a theme to see preview
   - Click to apply
4. **Customize**:
   - Adjust colors
   - Change fonts
   - Modify spacing
   - See changes in real-time

### Step 7: Preview Website

1. Click the **"👁️ Preview Website"** button (bottom of sidebar)
2. **View Mode**:
   - See your complete website
   - Navigate between pages
   - Check all links work
3. **Edit Mode**:
   - Click "Edit Mode" toggle
   - Click any text to edit inline
   - Changes save automatically
   - Click "View Mode" to return to preview

### Step 8: Export Website

1. Click the **"📦 Export"** button (if available)
2. Choose format:
   - **Static HTML**: Pure HTML/CSS/JS
   - **Laravel 12.x**: Complete PHP project
   - **React + Node**: Full-stack JavaScript
3. Configure options:
   - Minify CSS/HTML
   - Include sitemap
   - Include robots.txt
4. Click **"Export"**
5. Download ZIP file
6. Extract and deploy!

## 🔧 Troubleshooting

### Login Not Working?

1. Clear browser cache (Ctrl+Shift+R)
2. Clear localStorage:
   ```javascript
   localStorage.clear()
   ```
3. Refresh page
4. Try login again with:
   - Email: `admin@websitefactory.com`
   - Password: `password`

### Pages Not Loading?

1. Check browser console for errors (F12)
2. Clear localStorage and refresh
3. Create a new project

### Theme Not Applying?

1. Go to Theme tab
2. Select a different theme
3. Wait for preview to update
4. If still not working, refresh page

### Export Failing?

1. Check if project has at least 1 page
2. Verify theme is selected
3. Check browser console for errors
4. Try a different export format
