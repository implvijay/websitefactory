## 🚀 Quick Start

### Installation
```bash
# Clone repository
git clone <your-repo-url>
cd website-factory

# Install dependencies
npm install

# Start development server
npm run dev
```

### Login
- **Email**: admin@websitefactory.com
- **Password**: password

### Create First Website
1. Click "New Project"
2. Enter project name
3. Select industry
4. Choose theme (from 48 options)
5. Click "Create Project"
6. Add sections to pages
7. Customize content
8. Preview website
9. Export in desired format
